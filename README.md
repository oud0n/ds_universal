## 🏎️ 本プロジェクトについて

モータースポーツ・サーキット走行用の超小型高精度GPSロガー **「デジスパイスIV（DigSpice IV）」** は、20Hz測位に対応した日本のサーキットユーザー定番のデータロガーです。

しかし、**公式ソフトウェアがWindows専用**であるため、
- 「サーキットにMacBookを持っていってもログが吸い出せない」
- 「公式アプリを起動せずにサクッと設定（20Hzへの変更や開始速度の変更）を行いたい」
- 「コマンドラインや自作スクリプトから自動でデータを吸い出したい」

といった不便さがありました。

本プロジェクト `ds_universal` は、デジスパイスIVの USB/COM（仮想COMポート）通信プロトコルをパケット解析（リバースエンジニアリング）し、**公式Windowsアプリを一切使わずに、Mac / Windows の両方から直接デジスパイスIVを操作・設定・ログ吸い出しできるようにしたツール群**です。

## ✨ 主な機能

1. **Mac / Windows 両対応の Electron デスクトップGUIアプリ**
   - サーキット現場でMacBookからワンクリックで接続・ログ吸い出し・設定変更が可能。
   - Chromium標準の **Web Serial API** を採用しているため、面倒なC++コンパイラやネイティブモジュールのビルド（`node-gyp` 等）が一切不要。
2. **Windows PowerShell CLI ツール (`digspice_cli.ps1`)**
   - コマンドラインから自動化スクリプト等に組み込み可能。
   - ポート番号の手動指定不要！ハードウェアID（VID: `0x2DCF`, PID: `0x6002`）による **COMポート完全自動検出**。
3. **現在の設定・状態の確認 (`GetConfig`)**
   - ファームウェアバージョン（DS4 v1.01等）
   - 現在のログ書き込みポインタ・保存済みログ容量（バイト数）
   - 測位レート（20 Hz / 10 Hz / 5 Hz）
   - ログ記録開始・停止速度（30 km/h 等）
   - バッテリー・内部ステータスコード
4. **測位・ログ記録レート変更 (`SetRate`)**
   - `20 Hz` (50ms周期、最高精度) / `10 Hz` / `5 Hz` へのワンクリック切り替え
5. **走行ログ自動記録 開始/停止 速度閾値の設定 (`SetSpeed`)**
   - 時速 10 km/h, 20 km/h, 30 km/h, 35 km/h などの閾値を自由に変更
6. **本体走行ログのダウンロード・吸い出し (`Download`)**
   - 内蔵フラッシュメモリからログデータを直接吸い出し、rawバイナリ（`.bin`）としてPCに保存。
   - プログレスバー（進捗率・アドレス表示）付き。
   - 有効ログが無い場合（未走行・消去直後）も安全に検出。
7. **本体ログの全消去 (`Erase`)**
   - 次回走行に備えたフラッシュメモリ全消去。
   - 誤操作防止の安全ロック機構（確認チェックボックス / `-Force` オプション）を完備。
8. **リアルタイム通信パケットログ表示**
   - デバイスとの送受信（NMEAテキスト・HEX）をリアルタイムにモニタリング可能。

## 💻 使い方 1: Electron GUI アプリ (Mac / Windows 共通)

MacBookやWindows PCで、画面を見ながら直感的に操作したい場合に最適です。

### 準備
Node.js (v18以降) がインストールされていることを確認してください。

### 起動手順

```bash
# 1. 依存パッケージのインストール（初回のみ）
npm install

# 2. アプリの起動
npm start
```

### 操作手順
1. デジスパイスIVを付属USBケーブルでPCに接続し、電源を入れます。
2. 画面右上の **「🔌 デバイスに接続」** をクリックします。
   - 自動的にデジスパイスIV（`VID: 0x2DCF, PID: 0x6002`）が認識され、接続されます。
3. 接続されると、現在のファームウェアバージョン、記録容量、設定レート（20Hz等）が自動表示されます。
4. 各種ボタンから操作：
   - **レート変更**: `20 Hz`, `10 Hz`, `5 Hz` ボタンを押すだけ。
   - **速度設定**: `30` などのプリセットを押すか、数値を入力して適用。
   - **ログ保存**: 「📥 ログデータをダウンロード」を押すと、PCの保存先ダイアログが開き、`.bin` ファイルとして保存されます。
   - **消去**: 「ログ消去を許可する」にチェックを入れてから消去ボタンをクリック。

## 📟 使い方 2: Windows PowerShell CLI (`digspice_cli.ps1`)

Windows環境でコマンドラインから素早く操作したい場合や、バッチ処理したい場合に便利です。

### 基本コマンド

COMポート番号の指定は不要です。自動でデジスパイスIVを検出します。

```powershell
# ① 現在の設定・ログ保存容量を確認
.\digspice_cli.ps1 -Command GetConfig

# ② ログレートを 20 Hz に変更
.\digspice_cli.ps1 -Command SetRate -Rate 20

# ③ ログレートを 10 Hz に変更
.\digspice_cli.ps1 -Command SetRate -Rate 10

# ④ ログ開始速度を 30 km/h に設定
.\digspice_cli.ps1 -Command SetSpeed -Speed 30

# ⑤ ログデータを吸い出してファイルに保存
.\digspice_cli.ps1 -Command Download -Output my_track_data.bin

# ⑥ 本体の全ログを消去 (誤消去防止のため -Force が必須)
.\digspice_cli.ps1 -Command Erase -Force
```

### COMポートを手動指定する場合
複数台接続時や、手動でポートを指定したい場合は `-Port` を追加します。

```powershell
.\digspice_cli.ps1 -Port COM3 -Command GetConfig
```

## 🔍 通信プロトコル仕様の概要

デジスパイスIVは、標準的な **USB CDC-ACM（仮想COMポート、115200 bps, 8N1）** で動作します。
通信はすべて **NMEA-0183 形式のテキストコマンド (`$<コマンド>*<チェックサム>\r\n`)** です。
チェックサムは `$` と `*` の間の全バイトに対する **XOR（排他的論理和）** です。

| コマンド | 説明 | 送信例 | 応答例 |
| :--- | :--- | :--- | :--- |
| **PMTK605** | ファームウェア・モデル確認 | `$PMTK605*31` | `$PMTK705,DS4,1.01*0D` |
| **PMTK182,2,8** | 次回書き込みポインタ取得 | `$PMTK182,2,8*33` | `$PMTK182,3,8,00000200*1C` |
| **PMTK400** | 測位周期確認 | `$PMTK400*36` | `$PMTK500,50,0,0,0.0,0.0*1E` (50ms=20Hz) |
| **PMTK300** | 測位周期設定 | `$PMTK300,50,0,0,0,0*18` | `$PMTK001,300,3*33` |
| **PTSI777,1** | 開始/停止速度取得 | `$PTSI777,1*34` | `$PTSI777,0,30.00*34` |
| **PTSI777,2** | 開始/停止速度設定 | `$PTSI777,2,30.00*36` | `$PTSI777,0,30.00*34` |
| **PMTK182,7** | フラッシュログ読み出し | `$PMTK182,7,0,1000*13` | `$PMTK182,8,00000000,<Hexデータ>*CS` |
| **PMTK182,6,1** | フラッシュ全消去 | `$PMTK182,6,1*3E` | `$PMTK001,182,6,3*21` |

※ より詳細なパケットシーケンス、ヘッダセクタ構造、フレームトレースは [protocol_analysis.md](protocol_analysis.md) をご覧ください。

## 🛠️ 開発者・解析者向けツール (`extract_pcap.py`)

Wireshark / USBPcap でキャプチャした `.pcapng` ファイルから、USBシリアル通信のペイロード（TX/RX）を抽出・可視化するPythonツールです。

```bash
# キャプチャファイルを解析してTX/RXペイロードを表示
python extract_pcap.py wireshark/set_rate_20.pcapng

# フォルダ内を一括解析
python extract_pcap.py wireshark/
```
