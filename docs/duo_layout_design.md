# iPhone Duo の配置 (PLAN-30 の検討)

2026-10-26。iPhone Duo (折りたたみ) を開いた画面を生かす配置と、開く・たたむときの画面の移り変わりの検討。BUG-36 もここで直す。

## 1. 画面の大きさ (シミュレーターで撮ったスクリーンショットから)

| 画面 | 大きさ (pt) | 向き | 今の配置 |
|---|---|---|---|
| 外 (たたんだとき) | 466 × 678 | 縦 | スマートフォン (縦)。ふつうの iPhone (390〜440) より少し広い |
| 内 (開いたとき) | 951 × 669 | 横長 (ふつうに持って) | スマートフォンの横向き (グラフとコース図を左右に) を引き伸ばしただけ |
| 内を縦に持つ | 669 × 951 | 縦長 | スマートフォン (縦) を引き伸ばしただけ |

- 今は `isPhone` (src/utils/device.ts) を、読み込んだときの画面の短い辺 (600 未満) で決め、そのまま変えない。Duo をたたんだまま起こすと、開いてもスマートフォンの配置のまま (スクリーンショットの状態)。開いたまま起こすとパソコンの配置になり、たたむと幅 600 未満の決まりでスマートフォンに替わる (このときは欄が作り直される。5)。
- 折り目の位置・半分開いた形 (机に立てる形) を取る方法は分からない。今回は使わない (画面の大きさだけで決める)。

## 2. 配置の段 (幅と高さで決める。端末の名前では決めない)

| 段 | 条件 | 当てはまる画面 |
|---|---|---|
| スマートフォン | 幅 600 未満、または高さ 500 未満 (横向きのスマートフォン) | iPhone・Duo の外・横向きの iPhone |
| **中くらい (新しい)** | 幅 600 以上 1024 未満で、指で触る画面 | Duo の内 (横・縦)・iPad mini の縦・iPad の Split View |
| パソコン | 幅 1024 以上、またはマウスの画面 | iPad の横・デスクトップ版・ブラウザ版 |

- `isPhone` は読み込んだときに決めず、画面の大きさが変わるたびに見直す (useCompactLayout と同じく matchMedia で)。
- 中くらいの段でも、押す所の大きさ・下のタブ・指の操作はスマートフォンと同じ (指で触るため)。並べ方だけを広げる。
- 横向きのスマートフォン (高さ 500 未満) は、今の横向きの配置のまま。

## 3. 中くらいの段の画面 (案)

下のタブ (タイマー・走行・解析・動画) と上の段 (開く・走行とコース・⚙) はスマートフォンと同じ。

### 解析

横長 (951 × 669):
```
┌──────────────────────┬─────────────────┐
│ 速度グラフ (+タイム差) │                 │
│                      │   コースマップ    │
├──────────────────────┤   (いつも出す)    │
│ [動画|GG|コーナー|…]  │                 │
│  下の欄 (1 つずつ)     │                 │
└──────────────────────┴─────────────────┘
  再生の段
```
縦長 (669 × 951): 上にグラフ、中ほどにコースマップ、下に「動画・GG・コーナー…」の欄の 3 段。

- スマートフォンでは「コース」も下の欄の 1 つだが、中くらいではコースマップをいつも出し、下の欄からは外す。
- 下の欄の既定は「動画」(動画があるとき)。走行を見返すときにいちばん使うため。
- BUG-36 のコースマップの上のボタンの折り返しは、中くらいではボタンを 1 段に収める (コーナーの編集・位置調整は ⋯ のメニューへ)。

### 動画

- 見る: 動画を大きく、右 (縦長では下) に小さなコースマップと速度。
- 比べる: Car 1・Car 2 を左右に並べる (縦長では上下)。3〜4 台は 2 × 2。BUG-36 の「Car 2 を足しても 1 つしか出ない」はここで直す。
- 合わせる: 今のスマートフォンの道具の段のまま。

### 走行

- 左に走行の一覧、右に選んだ走行の詳細 (一覧と詳細を並べる)。スマートフォンのように詳細へ移らない。

### ラップタイマー

- 測る前: 今と同じ。
- 測っている間: 大きな数字 (今の周・前の周・差) の横にコースマップ。スマートフォンの横向きの配置を、広さに合わせて大きくする。
- 部品は大きく、少なくのまま (ヘルメット・グローブで見るため)。

### 設定・ロガー・変換

- スマートフォンと同じで、中身の幅だけ広げる (最大 720 くらいで真ん中に)。

## 4. 開く・たたむときの移り変わり

### 変えないもの (どの画面でも)

- 今のタブ、開いている走行・Car 1〜4・選んでいる周、再生の位置。
- 再生中なら再生を続ける (動画は作り直さないので途切れない。作り直すときは位置を合わせて続ける)。
- ラップタイマーで測っている・撮っている間は、配置を広げるだけで、測る・撮るは止めない。確認の窓 (測定終了など) も開いたまま。
- 開いている引き出し (走行とコース)・⚙ の画面。
- 欄ごとの表示の設定 (コースマップの拡大・追従・色分け、グラフの拡大など)。

### 画面ごとの移り変わり

| 画面 | たたむ → 開く | 開く → たたむ |
|---|---|---|
| 解析 | 下の欄で「コース」を出していたら、コースは右へ、下の欄は「動画」(無ければ GG)。ほかの欄なら、その欄のまま右にコースを足す | 最後に触った欄を下の欄にする (コースを触っていればコース) |
| 動画 (見る) | 小さなコースマップと速度を足す | 外す |
| 動画 (比べる) | 上下 → 左右に並べ替える | 左右 → 上下 |
| 走行 | 詳細を開いていれば、一覧の横に詳細 | 詳細を出していれば詳細の画面、出していなければ一覧 |
| タイマー | 数字の横にコースマップ | 今の配置 |

- 開く・たたむ間は、画面の大きさが何度か変わる (ヒンジの動き)。配置の段は大きさが 0.15 秒変わらなくなってから切り替え、途中でちらつかせない。
- 切り替えで動くもの (コースマップの位置など) に動きの効果は付けない。

## 5. 作り方で気をつけること

- **今の App.tsx は、スマートフォンとパソコンで欄を置く木が別**なので、配置を替えると欄が作り直され、表示の設定 (拡大・追従など) が消え、動画も読み直しになる。中くらいの段を足すときに、欄は 1 度だけ作り、置き場所 (CSS grid の場所) だけを替える形にする。どうしても別の場所に置くときは、設定を欄の外 (useWindowView のような覚え) に出しておく。
- 解析の動画は、置き場所が替わっても同じ 1 つの動画の窓を使う (スマートフォンの下の欄の動画と、中くらいの段の動画を同じ印 (viewKey) にする)。
- メーターの配置の編集はパソコンだけのまま (中くらいの段でも並びを選ぶだけ)。
- 試し方: デスクトップ版・Chrome で、画面の大きさを 466 × 678 → 951 × 669 → 669 × 951 と変え (CDP の画面の大きさの指定)、変えないもの (4) が変わっていないかを e2e で確かめる。最後にシミュレーターの iPhone Duo と、手に入れば実機で。

## 6. 作る順番 (案)

1. `isPhone` を見直し、配置の段を 3 つにする (中くらいはまずパソコンの配置を指で触れる大きさにしただけでもよい)。BUG-36 の残り 2 つ (比べるの「この時刻の映像はありません」・ラップタイムの先頭のサーキット) を直す
2. 解析の中くらいの配置と、移り変わりの決まり (欄を作り直さない)
3. 動画 (比べるを左右に)・走行 (一覧と詳細を並べる)
4. タイマー
5. e2e で開く・たたむの試験。シミュレーター・実機

## 7. 決めてほしいこと

1. 開いた解析の下の欄の既定を「動画」にしてよいか
2. 中くらいの段で、メーターの配置の編集 (つかんで動かす) を出すか (今の決まりではパソコンだけ)
3. 開く・たたむで再生中だったら、再生を続けるか、止めるか
4. iPad mini の縦・iPad の Split View も同じ中くらいの段にしてよいか (同じ作りで当たる)
