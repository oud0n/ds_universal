# 入り口と画面の見直し (PLAN-47〜54)

2026-11-05。「機能が増えて使いにくくなった」という声 (みんカラ) と、持ち主の実機 (iPhone Duo) の確かめから。どの入り方をしても、最初に押すボタンが 1 つか 2 つになるようにする。
叩き台を 3 つの立場 (初めて触る人・走行会の常連・作り手) で見直した結果をまとめた。見本の図は持ち主の手元にある。

## 1. 使う人の入り方

| 入り方 | 道 | つまずき |
|---|---|---|
| スマホ → PC | iPhone で測る → 保管場所は iCloud Drive の LapLoupe → Mac のアプリが同じ場所を見つける | Windows は iCloud for Windows が要る。iCloud の同期待ち |
| PC → スマホ | PC でデジスパイスを見る → iPhone のアプリで同じ保管場所を使う → サーキットでタイマー・ロガーの受け手に | PC で iCloud 以外のフォルダにためていると、iPhone から見えない |
| ブラウザだけ | ファイルを落とすか見本で試す | 開いた走行は残らない。大きな動画 |
| 動画の人 | GoPro の動画を開く → GPS から走行を作る → メーターを付けて書き出す | 解析を通らずに動画へ行きたい |
| 何も持っていない | 見本 (袖ヶ浦 12 周) を開く | 見本と自分の走行が混ざらないように (保管場所に入れない) |
| Windows + iPhone | iPhone から共有で送る → PC で取り込む | 動画が重い。二重の取り込み |
| 端末を替えた・入れ直した | 保管場所の走行に気づける | 走行が無いように見える |
| LINE・メールでログを受け取った | 「LapLoupe で開く」から開ける | 開き方が分からない |

## 2. 今の事実 (コードで確かめた)

- iPhone は起動したときに許可を求めていない。Bluetooth は機器を探す・つなぐときに初めて (BleModule.swift・nativeBleCentral.ts)、位置はタイマーで「この iPhone」で測るときに初めて (timerRuntime.ts・positionFeeds.ts)。
- タイマーを出すかは環境だけで決まり、利用者の設定は無い (device.ts・appProfile.ts)。判断は navPlan.ts・App.tsx・DevicesCard・ロガーに散っている。
- デスクトップ版の保管場所はダイアログで選ぶだけ (main.cjs)。iPhone は選んだフォルダを bookmark で覚えるだけで、「LapLoupe」は慣例の名前。
- 見本 (public/demo/sodegaura_20260815.nmea) はまだ画面から開けない。
- 下のタブはすでにホームのバーの分を下に取っている (MobileNav.tsx)。文字が上に寄るのは余白の配分。

## 3. 決めたこと

### 3.1 入り口 (新しい画面は作らない)

- 走行の画面の空の状態に、「何を持っていますか」で 4 つの大きなボタン: ロガーのログ / GoPro などの車載動画 / iPhone だけ (これから測る) / まだ何も無い (見本)。
- 保管場所に走行があれば「iCloud Drive の LapLoupe に走行が N 件あります。これを使う」。
- 画面の上の「次にやること」の帯は作らない (広告と思って消される・グラフが狭くなる)。案内は空の欄の中の大きなボタンと、測り終えた直後の 1 回だけの知らせ。

### 3.2 ラップタイマーを使う・使わない

- 設定に「ラップタイマーを使う」。今の利用者はオンのまま。
- オフ: タイマーのタブ・GPS・ペアリング・機器の登録を出さず、機器を探す動きも止める。空の状態から 1 回で切り替えられる。

### 3.3 保管場所

- デスクトップ版の最初 (保管場所が未設定の人だけ): Mac は「iCloud Drive の LapLoupe (iPhone と同じ)」を先頭に。Windows はフォルダを選ぶのと、iPhone から送る方法。「あとで決める」も選べる。
- 設定に「保管場所を iCloud Drive へ写す」(PC で別のフォルダにためていた人)。
- ブラウザ版: 開いている間、上に小さく「この走行は保存されていません」。閉じるときに確かめる。

### 3.4 ラップを選ぶ (「走行とコース」を分ける)

- 「走行とコース」には、割り当て・周の表・コースの設定・補正・名前とメモが 1 つに詰まっていて分かりにくい。
- 新しい「ラップを選ぶ」: 左に走行の一覧 (すべての走行 / 走行ごと)、右にそのコースの全部の周の表 (タイム・走行・周・最高速、速い順 / 日付順) と、各行に Car 1〜4 のボタン。開いていない走行の周を押すと、裏で読み込んで割り当てる。
- 開く所: 解析の上の「＋ ラップを足す」と、走行の画面の「ラップタイム」。
- 今の中身の行き先: コースの選択・計測線・コースの編集 →「コース」(自動で決められなかったときだけ解析の上に「コースを決める」)。距離補正・時計の補正・1 周の長さをそろえる → 解析の上の Car のチップのメニュー。名前・メモ・保存 → 走行の画面の詳しい表示。
- 気をつけること: 控えの周の番号は、計測線を変えた走行では読み込んだときとずれることがある (割り当ての前に番号と時間を照らす)。開いておく走行は Car の分の 4 本まで。ブラウザ版は開いたファイルの周だけ。

### 3.5 解析の画面

- いちばん上に比べるラップのチップ (Car 1〜4、＋ ラップを足す)。
- 配置のプリセット: 「標準 (3 欄)」と「動画も (4 欄、今と同じ)」。動画がある走行は自動で「動画も」。切り替えても再生を止めない (今は欄を開くと再生が止まる作り)。
- コース図の色分け (車両色・車速・加減速・ライン偏差)・セクター・コーナー番号・Car 1 に合わせるは並べたまま (1 周の中で何度も押す)。「表示 ▾」には使う回数の少ないものだけ。
- 開発支援は ⚙ へ。タブの名前は言葉に (G の円・コーナー・ブレーキ・X/Y グラフ)。
- 欄の大きさとたたんだ状態の保存は、新しい配置に移しても捨てない。メニューを閉じたらグラフにフォーカスを戻す (Space・矢印のキー操作)。

### 3.6 スマホ

- 下のタブは、文字の入る所を高くし (8〜12pt)、真ん中に置く。
- 解析は、上にチップ、真ん中にグラフ、その下を「コース図 / 動画 / G の円 / コーナー」の切り替え。

### 3.7 テーマ (PLAN-45)

- いちばん最後。Phonotheque のガイドの Paper (役割の色 11 個)。ラップタイマーの画面だけはテーマの外で見やすさ優先 (昼 = 白地に黒 / 夜 = 黒地に白を手で切り替え)。
