## 1. デジスパイスIV USB通信・ロガー設定 (`LoggerTab`)
- **Web Serial API による直接通信**: ネイティブドライバのビルド不要で、USBケーブル1本で接続可能。
- **本体ログ高速ダウンロード**: 走行データを一括ストリーミングダウンロードし、公式互換の `.bnx4` 形式で保存。
- **各種設定変更**: 測位レート（`20Hz` / `10Hz` / `5Hz`）、記録開始/停止速度（5〜100km/h）を書き換え、本体から読み戻した値で反映を確認。
- **本体メモリ消去**: 次回走行前のフラッシュメモリ全消去（誤消去防止ロック付き）。

## 2. 本格モータースポーツ・テレメトリ解析 (`Graph / DataTab`)
- **速度グラフ比較**: 最大4台（または4ラップ）の車速・距離を重ね合わせ比較。
- **コースマップ & 走行軌跡**: OpenStreetMap / 自作サーキット定義に対応したコースプロット。国土地理院の航空写真・地図を背景に表示でき（要インターネット接続）、GPS 軌跡に合わせて地図の位置を微調整可能。
- **Gフォース・フリクションサークル**: 加速・減速・コーナリングGの分布とフリクションサークル表示。
- **コーナー解析**: コーナーを自動検出し、進入・ボトム・脱出速度を車両（ラップ）間で比較。
- **ブレーキング診断**: 制動開始位置、最大減速G、立ち上がり、リリース、トレイルブレーキングを数値とグラフで表示（GPS 車速からの推定）。
- **走行ライン偏差ヒートマップ**: 基準ラップに対する走行ラインの左右のズレをコース図上に色分け表示。ラップ間の GPS の位置ずれは自動で補正。
- **他形式の読み込み**: Racelogic VBO・RaceChrono CSV・GPX・MoTeC CSV（i2 の書き出し）・AiM（Race Studio の CSV、ロガーのファイル .xrk / .xrz の GPS）に対応。
  - MoTeC と AiM は、インターネットで公開されているサンプルのファイルで確かめただけで、開発者が自分の実機で記録したログでは確かめていません。うまく読めないファイルがあれば Issue でお知らせください。
- **Garmin などの FIT・TCX**: 腕時計やサイクルコンピューターの記録（.fit・.tcx）を「ファイル読込」で開けます。記録は 1 秒ごとのものが多いので、ラップタイムの細かさはデジスパイスなどより落ちます。
  - FIT・TCX は、公開されている仕様に沿って作ったファイルで確かめただけで、実機の記録では確かめていません。
- **RaceBox**: RaceBox のサイトの書き出しで VBO か GPX を選ぶと、そのまま読めます。CSV は書き出しの設定で列が変わりますが、時刻（秒か日時）・緯度・経度の列があれば読めます（実機の CSV では確かめていません）。
- **iRacing のテレメトリ（.ibt）**: iRacing で記録したテレメトリを「ファイル読込」で開くと、緯度・経度で実車のログと同じコースに重ねて比べられます（ゲームで練習した走りと実車の走りのブレーキを踏む位置などを比べるため）。アクセル・ブレーキ・ハンドルの角度・回転数・ギアも読み、速度グラフにアクセル（実線）とブレーキ（点線）を重ねて表示できます。コースに出ていた間ごとに別のログになります。G は実車のログと同じく位置と車速から計算します。
  - 公開されているサンプル（筑波 2000）で確かめただけです。iRacing でテレメトリを記録するには、iRacing の設定でディスクへの記録を有効にしてください（走行中に Alt + L でも切り替えられます）。
- **GoPro の動画の GPS**: GoPro（HERO5 以降の GPS 付きの機種）で撮った動画（.MP4）を「ファイル読込」で開くと、動画に記録された GPS を走行ログとして読み込みます。同じ動画は動画同期にも登録され、GPS の時刻で合わせた状態で再生できます。1 回の撮影が複数のファイル（チャプター）に分かれているときは、まとめて選ぶと 1 つのログになります（動画は端末内で読み、全体をメモリに載せません）。
- **ログ変換ページ**: 読み込んだログを NMEA（GGA + RMC）・GPX・VBO・CSV・TXT（空白区切り）・KML（Google Earth 用、線の色は車速）・DTB・地図 HTML（カーソルを乗せると時刻・車速を表示）・MoTeC CSV と、デジスパイス形式の走行データ CSV（G 付き）・ラップ一覧 CSV に書き出し。ログ全体 / ラップ 1 周 / 時間指定（グラフで切り出し）の範囲と、時刻の調整（時差）を選べます。書き出しはすべてこのページにまとめ、データ管理の各ログの「変換画面で開く」から開けます。

### コースデータ（計測線）について
- **内蔵プリセット**: 国内 101 コース（サーキット・カートコース）と海外 26 サーキット（アメリカ・オランダ・フランス・スペイン）の名称と中心座標、うち 126 コースのスタート / フィニッシュの計測線を内蔵しています。いずれも本アプリ独自のデータで、中心座標は OpenStreetMap のコース形状から、計測線は航空写真（国内は国土地理院、海外は各国が自由に使えるとしているもの）でスタートライン付近の位置を確認して作成しています（海外の 3 コースは写真で確かめられなかったため、ピットロードの中ほどの仮の位置。写真で路面の線が見えなかった 3 コースは推定。国内のカートコースなどの多くは、OpenStreetMap のコースの線に直交させた推定の位置で、写真で路面にかかることだけを確かめています）。周回の区切りには使えますが、各サーキットの公式計測位置と一致するとは限りません（区切る位置が違うと、同じ走行でも各周のタイムは少し変わります）。73 コースにはセクター線も入れています（SUGO は公式のコース図の計測地点、鈴鹿・富士はレースの区間の分け方から推定、もてぎは 4 等分、ほかは 3 等分の仮の位置）。データはデジスパイスと同じ形式のファイル（.cln・.sci）で [`courses/`](../courses/) に置いて同梱しています。位置が違うときは、[コースデータの Issue](https://github.com/oud0n/ds_universal/issues/new?template=course.yml) でお知らせください（コース編集で直した .cln / .sci を添付してもらえると助かります）。
- **お手持ちのコースデータを使う場合**: デジスパイス公式ソフトをお持ちの方は、ご自身の PC にあるコースフォルダ（`Circuit` / `ControlLine` / `Sector` を含むフォルダ）を、データタブの「コースフォルダ一括設置」で読み込めます。読み込んだデータは内蔵プリセットより優先されます。本アプリは公式ソフトのコースデータを同梱・配布していません。
- **知らないコース**: 内蔵のコースにないコースのログは、周回していれば計測線を自動で置きます（ピットロードの横の直線＝メインストレートの真ん中。毎周通ることを確かめて置きます）。セクターがなければ、速い周を距離で 3 等分した所にセクター線を置きます。自動の線は公式の計測線とは少しずれることがあるので、正確なタイムが要るときは「コース編集」で直してください。周回していないログは、走り始めに仮の計測線を置きます。
- **計測線が無いコース**: データタブの「コース編集」で計測線の 2 点（緯度・経度）を入力するか、`.cln` ファイルを読み込んでください。計測線が未設定、または走行中に通過していない場合は、データタブに案内が表示されます。
- 出典: 内蔵プリセットの座標は [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) のデータ（[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)）と、[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)のシームレス空中写真をもとに作成しています。該当するデータは [`courses/`](../courses/) のファイルです（作り方は [`courses/README.md`](../courses/README.md)）。SUGO のセクターの位置は[スポーツランドSUGO のコース図](https://www.sportsland-sugo.co.jp/assets/docs/course/c-racing/2026_racing-course_layout.pdf)の計測地点の距離を使っています。

## 3. 車載動画（GoPro / DJI / 一般MP4）自動同期 (`VideoSyncWindow`)
- **タイムゾーン完全自動判定 & 9時間時差スキャン**: GPS座標（日本国内ならJST自動判定）と動画メタデータ（UTC/JST）から時差を自動検出・ミリ秒単位でオフセット補正。
- **GoPro 4GBチャプター分割ファイルの自動連続再生**:
  - `GX010017.MP4` $\rightarrow$ `GX020017.MP4` $\rightarrow$ `GX030017.MP4` などの分割ファイルを自動検出・直列連結。
  - チャプター境界を跨ぐシームレス自動連続再生に対応。
- **動画編集ソフト風 NLE マルチトラック・タイムラインインスペクター**:
  - セッション絶対時間に対して、GPS走行ログ（各ラップ区間）と車載動画（各チャプタークリップ）がどの時間帯にマッピングされているかを一目で可視化。
  - タイムライン上を直接クリック＆ドラッグしてスクラブ（シーク）可能。
- **速度ウィンドウとの完全双方向シーク同期**:
  - 選択中ラップ（またはセッション全体）の時間軸にシークバーが完全同期。
- **前後2カメラ / PinP（ピクチャー・イン・ピクチャー）同時同期再生**:
  - 前方車載と後方カメラ（またはペダルカメラ等）を2画面（左右 1:1）またはPinPで完全同期再生。
- **手動キーフレーム同期（Sync Pin）**:
  - 縁石のクリッピングポイントやコントロールライン通過フレームで「ピン留め同期」を押すだけでオフセットを一発固定。
- **動画テレメトリ焼き込みエクスポート（Overlay Burn-in Export）**:
  - 速度計・Gボール・ラップタイムを合成したMP4動画をブラウザ標準機能のみで直接レンダリング・書き出し。
- **フラットデザイン（Flat Design）**:
  - プロ仕様のモータースポーツ解析ツールらしい、無駄な影や丸みを抑えたクリスプな高視認性UI。

## 🌐 ブラウザ版で外部と通信するもの

インストールせずに、ブラウザからそのまま使えます。ログの読み込み・解析・変換はお使いの端末内で行い、ログをサーバーへ送信しません。

外部と通信するのは、地図の表示（地図タイルの取得）、コース定義の自動取得（コース中心の座標を OpenStreetMap の Overpass API に送信）、書き出した地図 HTML を開いたとき（表示用スクリプトを unpkg.com から、地図タイルを OpenStreetMap から取得）です。また、ブラウザ版はアクセス数を数えるために [GoatCounter](https://www.goatcounter.com/) を使っています（開いたページ・参照元などを送ります。Cookie は使わず、ログの内容は送りません）。デスクトップ版には入っていません。

- 解析画面: <https://oud0n.github.io/ds_universal/>
- ログ変換ページ: <https://oud0n.github.io/ds_universal/#convert>

ロガーとの USB 通信（ロガー設定タブ）は Web Serial API を使うため、**Chrome / Edge（PC 版）でのみ動作**します。Safari / Firefox やスマートフォンでは、ログの読み込み・解析・変換だけが使えます。

## 🚫 実装していない機能

- **公式ソフトのドリフト採点方式**: デジスパイス株式会社の著作権を侵害する可能性があるため、実装していません（実装の予定もありません）。
  本アプリ独自の簡易的な「ドリフト」表示もありましたが、2026-10-17 に表示をやめました。
- ロガーのログデータの読み込み・変換は、記録されたデータそのもの（位置・時刻・車速など）とファイルの付随情報を扱う一般的な解析であり、上記とは区別しています。
