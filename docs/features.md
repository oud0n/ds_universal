# LapLoupe の機能

**日本語** | [English](features.en.md)

[README に戻る](../README.md)

1.1.0 (2026-10-27) の時点で使える機能。版ごとの変更は [リリースノート](release-notes.md)、使い方の手順はアプリの「使い方」(ブラウザ版は https://oud0n.github.io/ds_universal/help/) にあります。

## 端末ごとにできること

| 機能 | ブラウザ版 | デスクトップ版 (Mac・Windows) | iPhone / iPad のアプリ |
|---|---|---|---|
| ログの読み込み・解析・変換・動画の同期と書き出し | ○ | ○ | ○ |
| デジスパイスの USB 通信 (吸い出し・設定) | Chrome / Edge (PC) | ○ | − |
| Bluetooth の機器 (デジスパイス・RaceBox・GoPro など) | Chrome (PC・Android) | ○ | ○ |
| 走行のライブラリ (保管場所のフォルダ・ラップタイムの一覧・名前やメモ・比べ方の保存) | − (比べ方はファイルに書き出し) | ○ | ○ (iCloud Drive などのフォルダ) |
| ラップタイマー (走りながら測る) | − | − | ○ (端末の GPS・デジスパイスなど、内蔵カメラで録画) |
| メーターの配置を作る (エディタ) | ○ (パソコン) | ○ | 並びを選ぶだけ |

iPhone / iPad のアプリは 2026-10-27 に App Store の審査に出しています。Android のアプリは試験版です。

## 1. ロガー・機器

- **デジスパイスIV の USB 通信**: 本体のログの吸い出し (公式互換の `.bnx4`)、測位レート (5 / 10 / 20 Hz)・記録開始速度の変更 (本体から読み戻して確かめる)、本体のメモリの消去 (誤って消さないロック付き)。ドライバは要りません。
- **Bluetooth (BLE)**: デジスパイスIV の Bluetooth、RaceBox Mini / Micro、Drogger (BLE)、心拍計、OBD-II (ELM327)、GoPro (HERO9 以降。測定開始で録画、終了で止める)。機器の画面で登録し、表示名とファイル名用の名前を付けられます。RaceBox・心拍計・OBD-II・BLE の Drogger は、公開の資料に沿って作っただけで、実機では確かめていません。
- **Android の試験版**: Bluetooth Classic の GPS (Drogger DG-PRO1S など) も使えます。

## 2. 走行のライブラリ (アプリ・デスクトップ版)

- **保管場所**: 選んだフォルダに `<サーキット>/<日付>/` の形で走行を置き、日付ごとに一覧にします。iPhone で iCloud Drive のフォルダを選べば、デスクトップ版でも同じ走行を開けます。
- **取り込み**: 1 本のログに複数のサーキットがあれば分けて、走行ごと・サーキットごとに取り込みます。
- **走行の情報**: 名前・メモ・車種・タイヤ・天候 (ドライ・ダンプ・ウェット・ヘビーウェット)・気温・路面温度。ファイルの名前は変えず、`runs.json` に書きます。
- **絞り込み**: 走行の一覧とラップタイムの一覧を、車種・タイヤ・天候で絞り込めます (ベスト・順位も絞った中で数える)。
- **ラップタイムの一覧**: 周ごとのタイム・セクター・最高速。走った順・タイム順、周を隠す。
- **参考ラップ**: 自分のではない走行 (動画だけのものも) を分けて持ち、比べる相手にできます。ベストには数えません。動画だけのものは、動画に計測線の印を打って周を作ります。
- **比べ方の保存**: 解析の Car 1〜4 の割り当てを保存して、あとで開き直せます。計測線を直して周の番号が変わっても、周の始まりの時刻で選び直します。
- **走行を消す**: その走行のファイルと記録だけを消します (同じ日のほかの走行・共有の動画は残す)。デスクトップ版はゴミ箱へ。iPhone・iPad のアプリ (次の版から) は、走行の一覧の「最近消した走行」へ移り、30 日のあいだは名前・メモ・同期ごと戻せます。

## 3. ラップタイマー (iPhone / iPad のアプリ)

- **位置の出どころ**: 端末の GPS (G センサーで間を埋めて 10 Hz)、デジスパイスIV (BLE)、RaceBox、Drogger。
- **測る**: 測定開始・終了の大きなボタン、コースの自動判定、周・セクター・タイム差、声で周のタイムを知らせる、測っている間は画面の向きを固める。走らずに終えた走行は消すか聞きます。
- **内蔵カメラで録画**: 測りながら録画 (前のカメラも一緒に、明るさの補正、ピントの固定)。動画は走行と同じフォルダに置き、同期した状態で開きます。熱くなりすぎたら録画だけ止めます。
- **センサーの記録**: 心拍計・OBD-II の値を `<走行>.<名前>.csv` に、端末の G センサーを `<走行>.iphone_imu.csv` に書きます。

## 4. 解析

- **速度グラフ**: 最大 4 台 (4 周) を距離・時間で重ねる。タイム差、セクター線、値の帯 (アクセル・ブレーキ・回転数・CSV の値・計算式の値を、値ごとの目盛りで)。
- **コース図**: 国土地理院の航空写真・地図の上に走行ライン。車両色・車速・加減速・ラインのずれの色分け、追従 (拡大して車を追う)、セクターからの一斉スタート、コーナーの番号と名前の編集 (`course/Corner/`)。
- **G**: フリクションサークル、縦・横 G (公式ソフトと同じ計算)、旋回半径。
- **コーナー解析・ブレーキング診断**: コーナーごとの進入・ボトム・脱出速度、制動開始位置・最大減速 G・トレイルブレーキング。
- **X/Y グラフ**、標高、ログごとの時計の補正 (機器ごとの GPS の遅れの見積もり)、距離の補正・周の長さの伸縮。
- **配置**: 画面の幅に合わせて、スマートフォン・中くらい (iPad の縦・iPhone Duo の開いた画面)・パソコンの並びに替わります。

## 5. 車載動画

- **同期**: GPS の時刻と動画の撮影時刻で自動で合わせる (タイムゾーンの判定)、手で合わせる (ずれの入力・同期ピン)、GoPro の動画の GPS、チャプター分割のファイルの連続再生、.LRV。
- **見る・比べる・合わせる**: 最大 4 台のマルチカメラ、走行比較 (Car 1〜4 を同じ地点でそろえて並べる)、動画に映る周への移動。
- **保管場所の動画**: 走行に付けた動画は、丸ごと読まずに必要な所だけ読みます (数 GB でも開ける)。

## 6. メーターと書き出し

- **メーターの配置**: 部品 (速度・G・ラップの欄・タイム差の棒・コース図・拡大した地図・値の棒・ハンドル・グラフの帯・画像など) をつかんで動かす・足す・消す・大きさを変える。テンプレート (標準・データ多め・グラフ・最小)、小さな枠用の並び、走行ごとに並びを覚える。パソコンで作り、アプリでは選ぶだけ。
- **書き出し**: メーターを焼き込んだ MP4 (1 コマずつエンコードする方式。コマが抜けず実時間より速い)・再生しながら録る方式、メーターだけの透明な動画 (PNG の連番の ZIP・WebM)、枠の並びのままの書き出し。範囲は周・全体・時間で決める。

## 7. CSV の形式と計算式

- ほかの機器・アプリの CSV の列が何の値か・単位・時刻の形をパソコンで決めて、保管場所の `formats/` に保存すると、開くときに自動で読みます (走行の横の `<走行>.<名前>.csv` も)。
- 値から新しい値を作る計算式 (四則・比べる・min / max / abs / sqrt / round)。値は値の帯と動画のメーターに出せます。

## 8. 読み込み・変換

- **読み込める形式**: デジスパイス (.bnx4 / .bon4 / .dtb)、NMEA、Racelogic VBO、RaceChrono CSV、GPX、MoTeC CSV、AiM (CSV・.xrk / .xrz の GPS)、Garmin などの FIT・TCX、RaceBox (VBO / GPX / CSV)、iRacing (.ibt)、GoPro の動画の GPS。
  - MoTeC・AiM・FIT・TCX・RaceBox の CSV は、公開のサンプルや仕様で確かめただけで、実機の記録では確かめていません。うまく読めないファイルがあれば Issue でお知らせください。
  - iRacing は、ゲームの走りと実車の走りを同じコースに重ねて比べるため (アクセル・ブレーキ・ハンドル・回転数・ギアも読む)。
- **ログ変換**: NMEA (GGA + RMC)・GPX・VBO・CSV・TXT・KML (線の色は車速)・DTB・地図 HTML・MoTeC CSV・.bon4、デジスパイス形式の走行データ CSV (G 付き)・ラップ一覧 CSV。ログ全体・1 周・時間で切り出し、時差の調整。

## 9. コース

- **内蔵プリセット**: 国内 101 コース（サーキット・カートコース）と海外 26 サーキット（アメリカ・オランダ・フランス・スペイン）の名称と中心座標、うち 126 コースのスタート / フィニッシュの計測線を内蔵しています。いずれも本アプリ独自のデータで、中心座標は OpenStreetMap のコース形状から、計測線は航空写真（国内は国土地理院、海外は各国が自由に使えるとしているもの）でスタートライン付近の位置を確認して作成しています（海外の 3 コースは写真で確かめられなかったため、ピットロードの中ほどの仮の位置。写真で路面の線が見えなかった 3 コースは推定。国内のカートコースなどの多くは、OpenStreetMap のコースの線に直交させた推定の位置で、写真で路面にかかることだけを確かめています）。周回の区切りには使えますが、各サーキットの公式計測位置と一致するとは限りません（区切る位置が違うと、同じ走行でも各周のタイムは少し変わります）。73 コースにはセクター線も入れています（SUGO は公式のコース図の計測地点、鈴鹿・富士はレースの区間の分け方から推定、もてぎは 4 等分、ほかは 3 等分の仮の位置）。データはデジスパイスと同じ形式のファイル（.cln・.sci）で [`courses/`](../courses/) に置いて同梱しています。位置が違うときは、[コースデータの Issue](https://github.com/oud0n/ds_universal/issues/new?template=course.yml) でお知らせください（コース編集で直した .cln / .sci を添付してもらえると助かります）。
- **お手持ちのコースデータを使う場合**: デジスパイス公式ソフトをお持ちの方は、ご自身の PC にあるコースフォルダ（`Circuit` / `ControlLine` / `Sector` を含むフォルダ）を、データタブの「コースフォルダ一括設置」で読み込めます。読み込んだデータは内蔵プリセットより優先されます。本アプリは公式ソフトのコースデータを同梱・配布していません。
- **知らないコース**: 内蔵のコースにないコースのログは、周回していれば計測線を自動で置きます（ピットロードの横の直線＝メインストレートの真ん中。毎周通ることを確かめて置きます）。セクターがなければ、速い周を距離で 3 等分した所にセクター線を置きます。自動の線は公式の計測線とは少しずれることがあるので、正確なタイムが要るときは「コース編集」で直してください。周回していないログは、走り始めに仮の計測線を置きます。
- **計測線が無いコース**: データタブの「コース編集」で計測線の 2 点（緯度・経度）を入力するか、`.cln` ファイルを読み込んでください。計測線が未設定、または走行中に通過していない場合は、データタブに案内が表示されます。
- 出典: 内蔵プリセットの座標は [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) のデータ（[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)）と、[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)のシームレス空中写真をもとに作成しています。該当するデータは [`courses/`](../courses/) のファイルです（作り方は [`courses/README.md`](../courses/README.md)）。SUGO のセクターの位置は[スポーツランドSUGO のコース図](https://www.sportsland-sugo.co.jp/assets/docs/course/c-racing/2026_racing-course_layout.pdf)の計測地点の距離を使っています。
- **自分のコース**: コース編集で計測線・スタートとゴールが別の線・セクター線・保存フォルダ名を決めると、保管場所の `course/` に入り、端末の間で同じコースになります。

## 🌐 ブラウザ版で外部と通信するもの

インストールせずに、ブラウザからそのまま使えます。ログの読み込み・解析・変換はお使いの端末内で行い、ログをサーバーへ送信しません。

外部と通信するのは、地図の表示（地図タイルの取得）、コース定義の自動取得（コース中心の座標を OpenStreetMap の Overpass API に送信）、書き出した地図 HTML を開いたとき（表示用スクリプトを unpkg.com から、地図タイルを OpenStreetMap から取得）です。また、ブラウザ版はアクセス数を数えるために [GoatCounter](https://www.goatcounter.com/) を使っています（開いたページ・参照元などを送ります。Cookie は使わず、ログの内容は送りません）。デスクトップ版には入っていません。

- 解析画面: <https://oud0n.github.io/ds_universal/>
- ログ変換ページ: <https://oud0n.github.io/ds_universal/#convert>

ロガーとの USB 通信（ロガー設定タブ）は Web Serial API を使うため、**Chrome / Edge（PC 版）でのみ動作**します。Safari / Firefox やスマートフォンでは、ログの読み込み・解析・変換だけが使えます。

## 🚫 実装していない機能

- **公式ソフトのドリフト採点方式**: デジスパイス株式会社の著作権を侵害する可能性があるため、実装していません（実装の予定もありません）。
  本アプリ独自の簡易的な「ドリフト」表示もありましたが、2026-10-17 に表示をやめました。
- ロガーのログデータの読み込み・変換は、記録されたデータそのもの（位置・時刻・車速など）とファイルの付随情報を扱う一般的な解析であり、上記とは区別しています。
