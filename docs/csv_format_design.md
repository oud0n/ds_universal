# CSV の形式の定義 (PLAN-08 の続き。検討)

2026-10-26。どこの機器・アプリの CSV でも、列が何の値かを人が決めて保存し、解析で開くときに自動で使う。

## 1. 今の作り

- CSV は見出しの名前で、決まった列 (時刻・緯度・経度・標高・速度・距離・G・旋回半径・方位・衛星数) だけを見分ける。単位は速度の m/s・mph だけ見出しから読む
- ほかの列 (回転数・水温・油圧・ブーストなど) は読み捨てる。見出しがよくある名前でないと、緯度・経度も見つからず読み込めない
- ラップタイマーが書く `<走行>.<機器>.csv` (心拍計・OBD) も、解析では読んでいない
- メーター・グラフに出せる値は決まった 10 種類だけ。計算式は無い

## 2. 形式の定義 (案)

1 つの形式 = 「どのファイルに当てるか」と「列ごとの意味」の組。保管場所の `formats/<名前>.csvformat.json` に置く (iPhone とデスクトップ版で同じ定義を使う。メーターの並びの overlays/ と同じ扱い)。

```json
{
  "version": 1,
  "name": "AiM の書き出し",
  "match": { "suffix": ".csv", "header": ["Time", "GPS Latitude", "GPS Longitude", "RPM", "Water Temp"] },
  "kind": "log",
  "headerRow": 14,
  "delimiter": ",",
  "time": { "column": "Time", "as": "seconds" },
  "columns": {
    "GPS Latitude": { "channel": "lat" },
    "GPS Longitude": { "channel": "lon" },
    "GPS Speed": { "channel": "speed", "unit": "km/h" },
    "RPM": { "channel": "rpm" },
    "Water Temp": { "channel": "custom:water", "label": "水温", "unit": "℃", "min": 40, "max": 120 },
    "Lap": { "ignore": true }
  }
}
```

- **当てるファイル (match)**: 名前の終わり (`.csv`・`.obd.csv`・`.hr_driver.csv` など) と、見出しの列。両方合うものを使う (ただの `.csv` はいろいろな機器のものがあるので、見出しで見分ける)。いくつも合うときは、見出しの列が多く合うほう
- **種類 (kind)**:
  - `log`: それだけで走行になる CSV (緯度・経度がある)
  - `sensor`: 走行の横に置く値だけの CSV (心拍計・OBD・別のロガーの回転数など)。時刻で走行の点に合わせて足す
- **時刻 (time)**: 秒・ミリ秒・UTC のミリ秒・日時の文字 (形を選ぶ)。`sensor` は UTC の時刻が要る (無いときは、走行の始まりからの秒として合わせ、ずれは手で直す)
- **列 (columns)**: 列ごとに、決まった値 (速度・回転数・アクセルなど) か、自分で名前を付けた値 (`custom:<名前>`。表示名・単位・目盛りの最小と最大) か、使わない、を決める。単位を換える倍率・ずれも持てる
- 今の決め打ちの読み方は、形式の定義が合わないときに今までどおり使う

## 3. 画面

- **作る・直す (パソコンだけ)**: 設定に「CSV の形式」。CSV を落とすと、見出しと最初の 20 行を表で出し、列ごとに「何の値か・単位・使わない」を選ぶ。決め打ちで分かる列は最初から入れておく。名前・当てるファイルの名前の終わりを付けて保存。書き出し・読み込み (人に渡せる)
- **使う (どこでも)**: 走行を開く・ファイルを読み込むときに、合う形式があれば自動で使う。走行の横にある `.csv` で形式が合うものは、自動で一緒に読む。スマートフォンでは直さない (一覧で見るだけ)
- 自分で名前を付けた値は、メーターの値の棒・数字の欄・グラフの帯の「値」の選びに出る。解析の速度グラフに重ねるかは別に決める

## 4. 計算式 (このあと)

- 値から新しい値を作る (例: `speed * 0.621` で mph、`rpm / gear`、`(brake > 10) * 100`)。四則・比較・min / max / abs だけの小さな式。メーターの並びと同じく保管場所に置く
- 形式の定義ができてから載せる

## 5. 作る順番 (案)

1. 形式の定義の読み書きと、当てるファイルの決め方 (単体の試験)。保管場所の `formats/` を iPhone・デスクトップ版で書けるようにする
2. 読み方: `log` と `sensor` (時刻で走行の点に合わせる)。自分で名前を付けた値を点に持たせ、メーター・グラフの値の選びに出す
3. パソコンの設定の画面 (表で列を選ぶ)
4. 走行を開くときに、横の `.csv` を自動で読む (ラップタイマーの心拍計・OBD の .csv も)
5. 計算式

## 6. 決めてほしいこと

1. 当てるファイルは「名前の終わり + 見出しの列」で見分ける形でよいか
2. 自分で名前を付けた値を、動画のメーターだけでなく、解析の速度グラフにも重ねられるようにするか
3. 値だけの CSV (`sensor`) の時刻が UTC でないときは、走行の始まりにそろえて手で直す形でよいか
