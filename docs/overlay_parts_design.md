# 動画に重ねる部品と、その配置の設計

2026-10-19。PLAN-06（メーターを焼き込んだ書き出し）・PLAN-08（DashWare の機能）・PLAN-14（部品だけの透明な動画）・PLAN-15（タイム差とセクタータイムの焼き込み）をまとめて作るための設計。
足りないものは docs/dashware_gap.md と docs/overlay_tools_gap.md から拾った。ほかのソフトのコード・部品のデザインは使わない。

作るのは、動画の作り替え（feat/video-rework、docs/video_sets_design.md）を dev にマージしてから。部品は、その作り替えでできた枠（VideoTile）と、枠の並びの書き出しの上に載せる。

## 1. 今あるもの

動画に重ねているのは 3 つだけで、位置は決まっている（`drawTelemetryOverlayOnCanvas`）。

- 速度（数字と棒。左下）
- G（フリクションサークルと合成 G。右下）
- ラップタイム（周の番号と経過時間。右上）

PinP の小窓が重なる隅だけ、部品を小窓の横へずらす。走行比較では枠ごとに同じ 3 つを、枠の大きさに縮めて描く。

## 2. 部品の一覧

データにない値の部品は、置けるが「データなし」と薄く出す（書き出しには描かない）。

### 2.1 ログの値

| 部品 | データ | 今のログで出るもの |
|---|---|---|
| 速度（数字・棒・針） | speed | 全部 |
| 回転数（数字・棒）・シフトライト | rpm | iRacing の .ibt だけ（今は） |
| ギア | gear | iRacing の .ibt だけ |
| アクセル・ブレーキ（縦の棒 2 本） | throttle・brake | iRacing の .ibt だけ |
| ハンドルの角度 | steering | iRacing の .ibt だけ |
| 高度 | altitude | 記録している形式だけ |
| 方位（コンパス） | heading | 全部 |
| 走行距離（周の中・全体） | distance | 全部 |
| 時刻（撮影の本当の時刻） | timestamp・時計の補正 | 時刻のあるログ |
| 衛星の数 | satellites | 記録している形式だけ |

### 2.2 計算した値

| 部品 | 中身 |
|---|---|
| G の数字（前後・横・合成） | accelG・corneringG・combinedG |
| フリクションサークル | 今の G の点と、直近 1 秒の軌跡（LATER-10 と同じ描き方） |
| 旋回半径・ドリフト角 | turningRadius・driftAngle |
| 勾配 | 高度の差 ÷ 距離（前後 50 m で） |
| 周の中の最高・最低・平均速度 | 周の点から |

### 2.3 周と区間

| 部品 | 中身 |
|---|---|
| ラップタイム | 今の周の経過時間。周が終わったら、その周のタイムを数秒出す |
| ベスト・前の周 | そのログのベストラップ・1 つ前の周のタイム |
| セクタータイム | 今の区間の経過時間と、終わった区間のタイム。自己ベストより速ければ色を変える |
| 理論ベスト | セクターのベストの合計（lapCalculator の theoreticalBestTime） |
| 周の番号・周回数 | 今の周 / 全部の周 |

### 2.4 比べ（PLAN-15）

| 部品 | 中身 |
|---|---|
| タイム差の数字 | 基準の周に対する今の差（+0.42）。解析画面のタイム差（calculateDeltaTimes）と同じ値 |
| タイム差の棒 | 差の大きさと向きを、真ん中から左右に伸びる棒で出す |
| 基準の周の選び方 | ベスト・理論ベスト・別のログの周・走行比較の Car 1 |

### 2.5 図

| 部品 | 中身 |
|---|---|
| コース図 | 周の軌跡と今の位置。走行比較では、比べる車の位置も色の点で出す |
| 値のグラフ | 速度など 1 つの値の線。「直近 N 秒」か「周全体と今の位置」 |

### 2.6 文字

| 部品 | 中身 |
|---|---|
| 決まった文字 | ドライバー名・車名・コース名・日付。ログにあれば自動で入る |
| 値の文字 | 「{speed} km/h」のように、文の中に値を入れる（Telemetry Overlay の Dynamic Text と同じ考え） |

### 2.7 最初に作るもの

1. 今の 3 つを新しい仕組みに移す（速度・G・ラップタイム）
2. タイム差（数字と棒）・セクタータイム・ベストと前の周（PLAN-15。解析の強みをそのまま出せる）
3. コース図
4. 回転数・ギア・アクセル・ブレーキ（データのあるログで）
5. 値のグラフ・文字・残り

## 3. 配置

- **位置と大きさは、映像の四角に対する割合で持つ。** 基準にする隅（四隅・上下の真ん中・中央）と、そこからの距離（幅・高さの割合）、部品の幅（映像の幅の割合）。解像度・枠の大きさ・書き出しの大きさが変わっても、同じ見た目になる。
- **部品ごとに持つもの**: 種類、位置、大きさ、不透明度、重ね順、出す・出さない、部品ごとの設定（単位、グラフの値など）。
- **編集の画面**: 動画の上で部品をつかんで動かし、角で大きさを変える。
  - 映像の 2% ごとの目盛りに吸い付く。外側 5% を「安全な枠」として線で出す（編集ソフトやテレビで切れない範囲）。
  - 部品の一覧（追加・削除・重ね順）は横の欄に出す。編集中は再生を止めず、動く値を見ながら置ける。
- **小窓をよける**: 今の PinP の処理を一般にする。小窓の四角に重なる部品は、重ならない側へずらす（隅を基準にした部品は横へ、真ん中の部品は上下へ）。
- **小さな枠用の並び**: 走行比較の 2×2 やスマートフォンの枠は小さいので、並びを 2 つ持つ。
  - 大きな枠（映像の幅が 640px 以上）用
  - 小さな枠用（既定は速度・タイム差・Car の札だけ）
- **テンプレート**: 並びに名前を付けて保存し、選べるようにする。
  - 同梱: 「標準」（今の 3 つ）、「走行比較」（タイム差を大きく）、「データ多め」（回転数・アクセル・ブレーキ・コース図）、「最小」（速度だけ）
  - 保存先: アプリの設定（ブラウザに保存）と、JSON のファイル（人に渡せる）
  - 同期プロジェクト（形式 2.0）には、使った並びの名前と中身を入れる

## 4. 描き方の仕組み

- **部品の定義（OverlayPart）**: 種類ごとに、要るデータ・既定の大きさ・設定の項目・描く関数を持つ。描く関数は (canvas, 部品の四角, そのコマのデータ, 設定) を受け取る。
- **そのコマのデータ（FrameData）は、コマごとに 1 回だけ作る。** 今の点（前後の点で補間）、周、区間、タイム差、比べる車の位置。部品ごとに探し直さない。
- **画面・書き出し・透明な動画は、同じ関数で描く。** 今と同じく canvas 2D。
- **数字のちらつき**: 今は時刻にいちばん近い点の値を出している。前後の点で補間し、数字の部品は 1 秒に 10 回だけ書き換える（棒・針・図はコマごと）。
- **単位**: km/h と mph、m と ft を設定で切り替える（英語の画面の既定は mph にしない。設定で選ぶ）。

## 5. 書き出し

- **今の書き出し（1 枠・枠の並び）**: 部品の並びをそのまま使う。
- **部品だけの透明な動画（PLAN-14）**:
  - ブラウザで作りやすいのは、透明の WebM（VP8 / VP9 のアルファ）。MediaRecorder で透明が残るかは、ブラウザごとに確かめる（要確認）。
  - 残らない環境では、PNG の連番を zip で書き出す（編集ソフトはどれも読める）。
  - ProRes 4444 の MOV は、ブラウザでは作れない。Electron 版で ffmpeg を使うかは、あとで決める。
- **高画質の書き出し（WebCodecs）**は、別の作業（提案済みのカード）。部品の描き方はこの設計のものを使う。

## 6. 作らないもの

- 360° の動画、タイムラプス、書き出しの順番待ち、撮影時刻の埋め込み（優先度が低い）
- 任意の CSV の列の割り当て（DashWare のデータプロファイル）。読み込みの話なので別に考える
- 部品の見た目を一から描くエディタ（DashWare のような）。部品ごとの色・大きさ・不透明度の設定までにする

## 7. 進め方（案）

1. 部品の定義と FrameData を作り、今の 3 つを移す（見た目は変えない）。設定は割合の位置で持つ
2. タイム差・セクタータイム・ベストと前の周・コース図を足す（PLAN-15）
3. 配置の編集の画面（ドラッグ・大きさ・目盛り・安全な枠）と、小さな枠用の並び
4. テンプレート（同梱・保存・JSON・同期プロジェクトへの保存）
5. 回転数・ギア・アクセル・ブレーキ・値のグラフ・文字
6. 部品だけの透明な動画（PLAN-14）

## 8. 決めてほしいこと

- **部品の見た目の方向**: 今のフラットな数字の表示に揃えるか、針のメーターも用意するか
- **最初に入れる部品**: 2.7 の順でよいか（タイム差・セクターを先にする案）
- **小さな枠の既定**: 速度・タイム差・Car の札だけでよいか
