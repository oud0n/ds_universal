# 実機での確認 (2026-10-25、feat/android)

1.1.0 の前に、実機でしか分からないものを確かめる。「自動」は Mac につないだ端末を Claude が CDP で動かして確かめるもの、「手で」は利用者が操作するもの。

## つなぐ前に

- iPhone: USB でつなぎ、画面のロックを外しておく (入れ直しと CDP に要る)。「このコンピュータを信頼」が出たら許可
- Android: エミュレーター (laploupe_test) は Claude が動かす。友人の端末は手で (APK を渡す)

## 自動 (Claude がやる)

書き込むもの (★) は、保管場所に試験用のフォルダ `e2e_test/` を作って試し、終わったら消す。★ は始める前に利用者に確かめる。

| # | 端末 | 確かめること |
|---|---|---|
| A1 | iPhone | 今のビルドを入れる (npm run build → xcodebuild → devicectl)。起動して走行の画面が出る |
| A2 | iPhone | 走行の画面の「自分の走行 / 参考ラップ」・走行の詳細・消す確かめの画面・保存した比べ方の、縦・横の画面の崩れ (スクリーンショット) |
| A3 | iPhone ★ | 走行を消す: e2e_test/ に同じ日の走行 2 本と付けていない動画を作り、1 本を消す。消すファイル・残すファイルと runs.json の行が合うか。iCloud のフォルダではゴミ箱 (最近削除した項目) へ移るか (移せず消したら知らせが出るか) |
| A4 | iPhone ★ | 保存した比べ方: Car 1・Car 2 を割り当てて保存 → 別の走行を開く → 保存した比べ方から開き直して同じ周に戻るか。消す |
| A5 | iPhone ★ | 動画だけの参考ラップ: e2e_test/ に動画を 1 本写し、印を打って保存 → 比べるで 2 つの動画が周の始まりにそろうか (iCloud の動画の読み込みの速さも見る)。やめる |
| A6 | iPhone ★ | 内蔵カメラの再生の録画 (過去のログを再生して、前後同時で録画): 2 本の .mov ができ、走行に付くか (前に許可をもらった試験と同じ) |
| A7 | Android (エミュレーター) | 0.2.2 の APK を作って入れる。選んだフォルダ (SAF) で A3〜A5 と同じこと。選んだフォルダで消すと、端末の中の写しとフォルダの両方から消えるか |
