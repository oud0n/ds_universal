# メーターの配置エディタ (PLAN-08) の仕様案

2026-10-25。利用者の希望: アクセル・ブレーキなどの任意の値の棒、ステアリング角、解析画面のグラフとコース図 (今どこを走っているか) を動画に重ねたい。動画と重ねたときに見やすい配置も考える。
前の設計 docs/overlay_parts_design.md (3 配置・4 描き方・10 置き場) を土台にする。10 で「置き場が足りなくなったら自由な配置を考える」としていたのが今回。

## 1. 何を作るか

1. **部品を増やす**: 値の棒・ハンドル・グラフの帯・コース図 (大きさ自由)・数字の欄
2. **自由に置く**: 動画の上で部品をつかんで動かし、角で大きさを変える (今の「5 つの置き場」をやめる)
3. **並びのテンプレート**: 見やすい並びを同梱し、自分の並びを名前を付けて保存する
4. 画面の重ね表示・焼き込みの書き出し・部品だけの透明な書き出しは、今と同じく 1 つの描き方で描く

## 2. 部品

| 部品 | 中身 | 設定 |
|---|---|---|
| 速度 | 今の数字と棒 | 単位 (km/h・mph) |
| G | 今のフリクションサークル | 円の大きさの上限 |
| ラップの欄 | 今の Best・Lap・セクター・タイム差 | 比べる周 |
| **値の棒** (新) | 1 つの値を棒で出す。縦・横。数字を添える | 値 (チャンネル)・最小・最大・色・向き・名前の札 |
| **ハンドル** (新) | ハンドルの絵を角度で回し、角度の数字を添える | 最大の角度 (絵の振れの上限) |
| **グラフの帯** (新) | 解析のグラフと同じ線を、横長の帯に描く。今の位置に縦の線。Car 2 (比べる走行) の線も重ねられる | 値 (1〜3 本)・横軸 (周全体 / 前後 N 秒)・Car 2 を出す |
| **コース図** (広げる) | 今の軌跡と今の位置に、Car 2 の位置・セクター線・コーナーの名前を足せる。大きさを自由に | Car 2 を出す・向き (北が上 / 進む向きが上)・コーナーの名前 |
| **数字の欄** (新) | 値を数字だけで出す (回転数・ギア・水温など) | 値・桁・単位・名前の札 |
| タイム差の棒 (新) | 基準の周との差を、左右に伸びる棒で出す (速い・遅いで色) | 振れの上限 (秒) |

アクセル・ブレーキを 2 本並べたいときは、値の棒を 2 つ置く (専用の部品は作らない)。テンプレートの「データ多め」に 2 本並べた形を入れる。

## 3. 値 (チャンネル)

部品で選べる値は、読み込んだログにあるものだけを一覧に出す (無い値は選べない)。

| 値 | 出どころ |
|---|---|
| 速度・加減速 G・横 G・合成 G・旋回半径 | どのログでも (GPS から計算) |
| アクセル・ブレーキ・ステアリング角・回転数・ギア | iRacing の .ibt、列を割り当てた CSV、OBD の .csv (`<走行>.obd.csv`) |
| 心拍・そのほかのセンサー | `<走行>.<機器>.csv` |
| iPhone の G センサー | `<走行>.iphone_imu.csv` |

**デジスパイスなど GPS だけのログ**: アクセル・ブレーキの値は無いので、その値の棒は置けない (代わりの値は作らない。2026-10-25 に決定)。速度・G・横 G などの棒は置ける。

## 4. 並べ方

- **位置と大きさは、映像の四角に対する割合で持つ** (前の設計の 3 と同じ)。解像度・書き出しの大きさが変わっても同じ見た目。
- 部品ごとに: 種類・位置 (x, y)・幅・高さ・不透明度・重ね順・出す / 出さない・部品の設定。
- **小さな枠** (走行比較の 2×2・スマホの枠) は、並びを別に持つ (既定は速度・タイム差だけ)。大きな枠の並びを縮めて描くと読めないため。
- **PinP の小窓をよける**: 今の隅の部品をずらす処理を、重なった部品を小窓の外へずらす形に広げる。

## 5. テンプレート (動画と重ねたときに見やすい並び)

車載動画は、上半分に前の景色、下に車内 (ハンドル・メーター) が映ることが多い。景色の真ん中 (進む先) と、ドライバーの手元は隠さない。部品は下の帯と上の隅に寄せる。

**標準** (今の 3 つ + コース図)
```
┌──────────────────────────────────────┐
│[コース図]                 [ラップの欄]│
│                                      │
│              (進む先)                 │
│                                      │
│[速度]                          [G]    │
└──────────────────────────────────────┘
```

**データ多め** (アクセル・ブレーキ・ハンドルがあるログ向け)
```
┌──────────────────────────────────────┐
│[コース図]                 [ラップの欄]│
│                                      │
│                                      │
│ ┌速度┐ ▮▮ (アクセル・ブレーキ) (ハンドル) [G]│
│ └───┘                                │
└──────────────────────────────────────┘
```

**グラフ** (解析のグラフを下に重ねる。走りの振り返り・比べる走行向け)
```
┌──────────────────────────────────────┐
│[コース図 (Car 2 の点も)]  [ラップの欄]│
│                                      │
│                                      │
│[速度][━━━━ 速度のグラフ (Car 1 / Car 2) ━━━━│━━]│
└──────────────────────────────────────┘
```
グラフの帯は下の 15〜20% の高さ・横いっぱい。今の位置の縦線と、Car 2 の線を重ねる。

**最小**: 速度とタイム差の棒だけ (SNS 向け・小さな画面)。

テンプレートは、ログにある値を見て既定を選ぶ (アクセルがあれば「データ多め」、無ければ「標準」)。

## 6. 編集の画面

- **デスクトップ版・ブラウザ版 (パソコン)**: 動画の画面に「メーターの配置」を足す。
  - 真ん中に動画 (止めても再生しても編集できる)。部品をつかんで動かし、角で大きさを変える。映像の 2% ごとの目盛りに吸い付く。外側 5% の安全な枠を線で出す。
  - 左に部品の一覧 (足す・消す・重ね順・出す / 出さない)、右に選んだ部品の設定。
  - 上にテンプレートの選び・保存・名前を変える・消す。
- **スマートフォン**: 編集は作らない。テンプレートを選ぶ・部品を出す / 出さないだけ (指で小さな部品を動かすのは難しいため。「並びの編集はパソコンで」と案内する)。保管場所のテンプレートは同じものが出る。

## 7. 保存

- テンプレートは保管場所の `overlays/<名前>.overlay.json` に置く (iPhone・デスクトップ版で同じ並びを使える)。保管場所の無いブラウザ版は、ブラウザに保存し、ファイルに書き出す・読み込むで人に渡せる (比べ方の書き出しと同じ)。
- 動画に使ったテンプレートの名前を、その走行の runs.json の行の動画に覚える (開き直すと同じ並び)。
- 形式 (案):
```json
{ "version": 1, "name": "データ多め", "aspect": "16:9",
  "parts": [
    { "type": "bar", "x": 0.30, "y": 0.80, "w": 0.03, "h": 0.15, "channel": "throttle", "min": 0, "max": 100, "color": "#22c55e", "label": "THR" },
    { "type": "steering", "x": 0.42, "y": 0.78, "w": 0.10, "h": 0.17, "maxDeg": 270 },
    { "type": "graph", "x": 0.15, "y": 0.80, "w": 0.83, "h": 0.17, "channels": ["speed"], "window": "lap", "car2": true }
  ],
  "small": [ ... ] }
```
- 同梱のテンプレートはアプリに入れる (保管場所には書かない。直したら「名前を付けて保存」で自分のものになる)。

## 8. 描き方

- 前の設計の 4 のまま: 部品の種類ごとに描く関数 (canvas, 四角, そのコマのデータ, 設定)。そのコマのデータはコマごとに 1 回作る。
- **グラフの帯は重い**ので、線の形 (周全体の点) は周・値・大きさが変わったときだけ作り直し、コマごとには今の位置の縦線だけ描く。
- 書き出し (1 コマずつエンコード) でも同じ関数を使うので、画面で見た並びがそのまま焼ける。

## 9. 作る順番 (案)

1. 部品の定義をまとめ直す (今の速度・G・ラップの欄・コース図を、位置と大きさを外から受け取る形に)。並びの形式とテンプレートの読み書き。同梱のテンプレート 4 つ。テンプレートを選ぶ画面 (スマホも)
2. 新しい部品: 値の棒・ハンドル・数字の欄・タイム差の棒・グラフの帯・コース図の Car 2
3. 編集の画面 (パソコン): つかんで動かす・大きさ・設定の欄・保存
4. 小さな枠の並び・PinP をよける・runs.json に覚える

1〜2 で「テンプレートを選ぶだけ」で使えるようにし、3 で自由に直せるようにする。

## 10. 決めたこと (2026-10-25)

1. スマートフォンは、テンプレートを選ぶ・部品を出す / 出さないだけ。つかんで動かす編集はパソコンだけ
2. GPS だけのログで、アクセル・ブレーキの代わり (加速 G・減速 G) は出さない
3. グラフの帯の横軸の既定は周全体 (部品ごとに前後 N 秒へ切り替えられる)
4. テンプレートは保管場所の `overlays/<名前>.overlay.json`。ブラウザ版はブラウザに保存し、ファイルで書き出す・読み込む
5. 同梱のテンプレートは 標準・データ多め・グラフ・最小 の 4 つ
