デジスパイス (DigSpice IV) を Mac で使う方法

デジスパイスの公式の解析ソフトは Windows 用で、Mac 版はありません。 Mac では、非公式の無料アプリ LapLoupe (ラップルーペ、旧名 DS Universal) を使うと、 USB でつないでログを吸い出し、本体の設定を変え、走行を解析できます。

LapLoupe は個人が作った非公式のソフトで、デジスパイスの販売元とは関係ありません。「デジスパイス」「DigSpice」はデジスパイス株式会社の商標です。

方法は 2 つ

デスクトップ版 (おすすめ)ブラウザ版
入れる物アプリ (Mac 用。Apple の公証を受けた署名付き)なし (ページを開くだけ)
対応する MacApple Silicon (M1 以降)どの Mac でも
USB での吸い出し・設定できるChrome・Edge だけできる (Safari はできない)
走行の解析・動画の同期できるできる
走行の保管と一覧 (ラップタイムの記録)できる (選んだフォルダ・iCloud Drive)できない (開いている間だけ)

デスクトップ版で使う手順

  1. GitHub の Releases から、Mac 用の .dmg を落として、LapLoupe を「アプリケーション」に入れます。
  2. デジスパイス IV を USB ケーブルで Mac につなぎます (ドライバは要りません)。
  3. LapLoupe の ロガー の画面で本体につなぎ、ログを吸い出します。公式と同じ形の .bnx4 で保存します。
  4. 測位の間隔 (5 / 10 / 20 Hz)・記録を始める速度も、同じ画面で変えられます (本体から読み戻して確かめます)。
  5. 吸い出したログを開くと、コースを自動で見分けて、周・セクターのタイムを出します。

ブラウザ版で使う手順

  1. Chrome か Edge で https://oud0n.github.io/ds_universal/ を開きます。
  2. USB でつなぐときは ロガー の画面から。すでにあるログ (.bnx4・.bon4・.dtb など) は、ファイルを選ぶだけで開けます (Safari でも)。

Mac でできること

  • ラップ・セクタータイムの一覧、周どうし・ほかの走行との比較 (最大 4 台)
  • 航空写真の上の走行ライン、車速・G のグラフ、フリクションサークル、コーナーごとの速度、ブレーキング
  • GoPro などの車載動画とログの同期、メーターを重ねた動画の書き出し
  • NMEA・GPX・VBO・CSV・KML などへの変換、ほかのロガー (AiM・RaceChrono・RaceBox など) のログの読み込み

使い方の詳しい手順は LapLoupe の使い方 にあります。

できないこと

  • 公式ソフトのドリフトの採点は、ありません (作る予定もありません)。
  • Windows 版の公式ソフトそのものを Mac で動かすものではありません。コースのデータは LapLoupe に入っているもの (国内 101・海外 26) を使い、公式ソフトのコースフォルダを持っていれば読み込めます。

よくある質問

Intel の Mac でも使えますか？
デスクトップ版は Apple Silicon 専用です。Intel の Mac では Chrome か Edge でブラウザ版を使ってください。

お金はかかりますか？
無料です。ログは端末の中だけで読み込み、どこにも送りません。

iPhone でも使えますか？
iPhone・iPad のアプリ (Bluetooth でデジスパイスとつないでラップタイマーとして使える) を公開の準備中です。ブラウザ版は iPhone でもログの解析ができます。

うまくいかないときは？
GitHub の Issue でお知らせください。作った経緯と通信の仕組みは Zenn の記事 にあります。
